# Dashboard de reventa de tenis en Excel
Tablero dinámico en Excel para analizar ~100,000 transacciones de reventa de tenis (Nike y Adidas/Yeezy), comparando el precio de reventa contra el precio de lanzamiento.
## Qué hice
- Limpié y organicé los datos en una tabla de Excel.
- Creé tablas y gráficos dinámicos: diferencial de precios en el tiempo, top modelos por diferencial en USD y en %, ventas por marca y un mapa por estado.
- Armé un tablero con segmentadores (región, modelo y año) conectados a todas las tablas.
